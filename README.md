## 📖 About the Certificate

The **TensorFlow Developer Professional Certificate** focuses on building practical deep learning applications using **TensorFlow**. Throughout the program, learners develop hands-on experience creating neural networks for:

- 🧠 Deep Learning
- 👁️ Computer Vision
- 💬 Natural Language Processing (NLP)
- 📈 Time Series Forecasting

The specialization emphasizes real-world implementation, model optimization, and best practices for building scalable AI applications. It consists of four hands-on courses and numerous programming assignments using Python and TensorFlow. :contentReference[oaicite:0]{index=0}

---

## 🎯 Learning Objectives

By completing this certificate, I learned how to:

- Build and train neural networks using TensorFlow and Keras
- Design Convolutional Neural Networks (CNNs)
- Apply Transfer Learning
- Perform image classification
- Prevent overfitting using:
  - Data Augmentation
  - Dropout
  - Regularization
- Process text using Natural Language Processing techniques
- Build Recurrent Neural Networks (RNNs)
- Train LSTM and GRU models
- Forecast sequential and time series data
